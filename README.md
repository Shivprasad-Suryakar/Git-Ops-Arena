# Git-Ops-Arena

A self-contained, single-file interactive Git quiz and practice web app with **Basic, Intermediate, and Advanced** tiers, **Light/Dark theme** support, and automatic `localStorage` progress save/resume.

## Key Features
- **Curated Git Questions** across core workflows (commits, branching, merging, rebasing, stash, reset/revert, remotes, and troubleshooting).
- **3 Sequential Tiers (`Basic` → `Intermediate` → `Advanced`):** Complete each tier to unlock the next level.
- **Auto-Save & Resume:** Progress is stored automatically in browser `localStorage` so you can resume anytime.
- **Zero Setup:** Runs as a single HTML file in your browser with no backend or build step required.

## Ways to Open & Play in Browser

### 1. Fork & Enable GitHub Pages
1. Click **Fork** at the top-right of this repository to copy it to your GitHub account.
2. In your forked repository, go to **Settings → Pages**.
3. Under **Build and deployment → Branch**, choose `main` (or `master`) and `/ (root)`, then click **Save**.
4. Open your published GitHub Pages link (`https://<your-username>.github.io/<repo>/git-ops-arena.html` or `https://<your-username>.github.io/<repo>/`).

### 2. Run Locally (Double-Click in Browser)
1. Download or save the HTML file onto your computer.
2. Open File Explorer and **double-click** the HTML file to launch it directly in your browser.

### 3. Netlify Drop (Instant Drag & Drop Hosting)
1. Save the HTML file (or `index.html`) in a folder on your computer.
2. Open **Netlify Drop** in your browser and drag-and-drop the file or folder.
3. Click the instant live URL provided to open the app in your browser.
